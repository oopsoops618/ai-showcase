# 作品集（GitHub Pages 用）

这个文件夹整体拷到一个新的 GitHub 仓库根目录，在仓库 Settings → Pages 里启用 Pages 功能（选主分支/根目录），几分钟后生成公开访问链接：

```
https://<你的GitHub用户名>.github.io/<仓库名>/
```

简历上挂这个链接（或者直接挂某个作品的二级链接，比如 `.../projects/ai-customer-service-eval.html`）。

## 目录结构

```
作品展示/
├── index.html                          ← 首页，作品集入口（不含真实姓名/联系方式）
├── projects/
│   └── ai-customer-service-eval.html   ← AI 客服智能体评估报告
└── README.md                           ← 本文件
```

## 新增作品时怎么加

1. 把新作品的 HTML 文件放进 `projects/`，文件名用英文/拼音，不用中文（链接分享出去更干净）
2. 打开 `index.html`，找到 `.grid` 里的 `<!-- 后续新增作品... -->` 注释，照上面那张卡片的格式复制一份 `<a class="card">`，改标题/描述/数字/链接
3. 不确定内容前不占位，没做完的作品不放"敬请期待"这类空卡片

## 脱敏检查清单（发布前过一遍）

- [ ] 不出现真实客户名/公司名
- [ ] 不出现真实姓名、电话、邮箱等个人联系方式（联系方式只出现在私下发送的简历 PDF 里，不放在公开网页上）
- [ ] 不出现内部文件路径、数据库地址、API Key 等技术敏感信息
